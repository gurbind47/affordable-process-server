# JSR Legals — Affordable Process Server

Static landing page for JSR Legals — Affordable Process Server — process serving and court support services for law firms and counsel, based in Brampton, Ontario and serving the GTA (Hamilton and Kitchener-Waterloo quoted on request).

Live site: https://gurbind47.github.io/affordable-process-server/

- `index.html` — the landing page and service request form (FormSubmit → info@jsrlegals.ca)
- `thank-you.html` — page shown after the form is submitted
- `assets/jsrlegals-rate-sheet.pdf` — downloadable rate sheet, built from `tools/rate-sheet.html`
